# 🎨 Como Adicionar o Logo EAS

## 📋 Instruções Rápidas

### Passo 1: Salvar a Imagem
1. Clique com o botão direito na imagem do logo EAS que você anexou
2. Selecione "Salvar imagem como..."
3. Salve com o nome: **`eas-logo.png`**

### Passo 2: Colocar na Pasta Correta
1. Navegue até a pasta do projeto: `Financa_codigo`
2. Entre na pasta: `public/images/`
3. Cole o arquivo `eas-logo.png` nesta pasta

### Passo 3: Verificar
O caminho final deve ser:
```
Financa_codigo/
└── public/
    └── images/
        └── eas-logo.png  ← Arquivo aqui!
```

## 🔧 Formato da Imagem

**Recomendações:**
- ✅ Formato: PNG com fundo transparente
- ✅ Tamanho: 800x600 pixels (ou proporção similar)
- ✅ Nome: `eas-logo.png` (exatamente este nome)
- ✅ Qualidade: Alta resolução para boa visualização

## 🚀 Após Adicionar a Imagem

1. Reinicie o servidor de desenvolvimento (se estiver rodando):
   ```bash
   # Pressione Ctrl+C para parar
   npm run dev
   ```

2. Acesse: http://localhost:3000

3. Você verá o logo EAS em:
   - Página de login
   - Header do dashboard
   - Footer de todas as páginas

## ⚠️ Importante

- O nome do arquivo DEVE ser exatamente: `eas-logo.png`
- A pasta DEVE ser: `public/images/`
- Se a imagem não aparecer, verifique:
  - O nome do arquivo está correto?
  - O arquivo está na pasta correta?
  - O servidor foi reiniciado?
