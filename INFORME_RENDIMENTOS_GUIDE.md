# 📊 Guia do Informe de Rendimentos

## ✅ Funcionalidade Implementada

Adicionei uma funcionalidade completa de **download de informe de rendimentos** que gera um relatório profissional com todas as receitas e investimentos.

### 🎯 **Localização:**
- **Dashboard** → **Configurações** → **📊 Informe de Rendimentos**

### 📋 **O que o relatório inclui:**

#### 1. **Resumo Financeiro**
- 💰 **Total de Receitas** do ano
- 📈 **Total Investido** no período
- 🎯 **Rendimento** (ganho/perda dos investimentos)

#### 2. **Receitas Detalhadas**
- Agrupadas por **categoria**
- Lista completa com:
  - Data da receita
  - Descrição
  - Valor individual
  - Total por categoria

#### 3. **Investimentos Completos**
- Agrupados por **tipo de investimento**
- Detalhes incluem:
  - Data do investimento
  - Nome do investimento
  - Valor investido inicial
  - Valor atual
  - Ganho/perda individual
  - Rendimento por tipo

### 🎨 **Características do Relatório:**

#### **Design Profissional**
- Layout moderno e limpo
- Cores organizadas por tipo de dado
- Tipografia legível
- Responsivo para impressão

#### **Formato HTML**
- Arquivo `.html` para visualização em qualquer navegador
- Otimizado para impressão
- Pode ser convertido para PDF pelo navegador
- Fácil compartilhamento

#### **Informações Completas**
- Cabeçalho com data de geração

- Dados organizados hierarquicamente
- Totais e subtotais calculados automaticamente

### 🚀 **Como Usar:**

#### **1. Acessar a Funcionalidade**
```
Dashboard → Config → 📊 Informe de Rendimentos
```

#### **2. Selecionar o Ano**
- Dropdown com todos os anos disponíveis
- Anos baseados nos dados existentes
- Preview mostra quantos itens serão incluídos

#### **3. Gerar o Relatório**
- Clique em "📥 Baixar Informe de Rendimentos [ANO]"
- Aguarde a geração (1-2 segundos)
- Arquivo será baixado automaticamente

#### **4. Visualizar/Imprimir**
- Abra o arquivo `.html` no navegador
- Use Ctrl+P para imprimir
- Ou "Salvar como PDF" no navegador
