# Instruções para adicionar o Logo EAS

## Passo a Passo:

1. Salve a imagem do logo EAS que você forneceu
2. Renomeie o arquivo para: `eas-logo.png`
3. Coloque o arquivo nesta pasta: `public/images/`
4. O caminho final deve ser: `public/images/eas-logo.png`

## Formato Recomendado:

- **Formato**: PNG com fundo transparente
- **Tamanho**: 800x600 pixels (ou proporção similar)
- **Nome do arquivo**: `eas-logo.png` (exatamente este nome)

## Onde o logo é usado:

- ✅ Página de Login (grande, centralizado)
- ✅ Navigation/Header do Dashboard (pequeno, ao lado do nome)
- ✅ Footer (pequeno, com informações de copyright)

Após adicionar a imagem, a aplicação irá carregá-la automaticamente!
